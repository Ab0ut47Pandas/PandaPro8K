# Earlier notes

These are the research notes from October 20–21, preserved so people can follow how the result was reached. Private paths and device instances were removed. The dated notes include hypotheses, dead ends and statements that were true before later tests.

Use [the current results](../docs/results.md) and [patch description](../docs/patches.md) for the final state. In particular, early statements that no firmware had been flashed, that wireless was untested, or that an r5 write prevented the receiver patch are superseded by the later physical tests and control-flow trace.

The full timing records are distributed as a separate captures release asset. The repository holds their index, hashes and summaries rather than large raw recordings or complete vendor firmware.
